Student team project · Kartverket / air ambulance scenario

Mapping obstacles. Supporting safer flights.

Recorded demo · 1:52

Application walkthrough: map-based reporting, review workflows and user administration. Download video ↗

A web application built around an obstacle-reporting scenario for helicopter operations. The recorded demo shows pilots placing obstacles on a map, registrars reviewing reports, and administrators managing users.

C#ASP.NET Core MVCMariaDBDockerLeaflet
What the demo shows
  • Map tools for point and line obstacles.
  • Obstacle type, height and description fields.
  • Pending, approved and rejected report statuses.
  • Separate pilot, registrar and administrator workflows.
  • User management with role selection.
Why it matters for security & consulting

The workflow provides a useful context for discussing user roles, data quality and responsibility. It also connects a concrete operational need to a digital service. These are discussion points, rather than claims of a security audit or a production deployment.
